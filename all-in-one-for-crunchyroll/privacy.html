Privacy Policy — All-in-One for Crunchyroll

Effective 26 October 2026 · Applies to version 1.1.0 and later
In short
  • The developer collects no data at all: no analytics, no tracking, no accounts, no ads.
  • Everything the extension saves stays in your own browser.
  • It only communicates with Crunchyroll and, if you choose to set it up, DeepL.
  • Nothing is ever sold or shared.

Who we are

All-in-One for Crunchyroll ("the extension") is an independent browser extension developed by Lance Landore in South Africa. It is not affiliated with, endorsed by, or sponsored by Crunchyroll, LLC. "Crunchyroll" is a trademark of its owner.

What the extension does on Crunchyroll pages

  • Subtitle tracks. To offer every subtitle language for an episode, the extension reads the subtitle list in Crunchyroll's own responses to the video player. To find tracks that belong to other audio versions of the same episode, it may make the same request Crunchyroll's player makes, using the sign-in session the page already has.
  • Your sign-in. The Crunchyroll sign-in token is used only inside the Crunchyroll page, only for those requests to Crunchyroll. It is never stored, never logged, and never sent to the developer or anyone else. Every extra playback session it opens is closed immediately.
  • Subtitle text is downloaded from Crunchyroll's servers and displayed on your screen. It isn't stored beyond the browsing session.
  • Skip markers. The extension reads the episode's intro/recap/credits timings, published by Crunchyroll, to skip those parts.
  • Speed and keyboard shortcuts are handled locally as you use them. Apart from the time-saved totals above, nothing about your viewing is recorded.

Optional machine translation (DeepL)

If you add your own DeepL API key and press Translate (and confirm), the text of the current subtitle track is sent to DeepL (api-free.deepl.com or api.deepl.com) to be translated. Nothing else is sent: no account details and no information about you. DeepL's handling of that text is covered by DeepL's privacy policy. The extension asks for permission to contact DeepL only when you save a key, and gives that permission back when you remove it.

Reporting a problem

The popup's Report a problem button shows a short text report that you can read and edit before copying it: the extension version, your browser version and language, your settings, and what the extension detected on the current episode page (for example how many subtitle tracks and skip markers it found). It never includes the page address, show titles, account details or your DeepL key, and includes the episode ID only if you tick the box. Nothing is sent automatically: the report goes only where you paste or email it yourself (the popup suggests allinone.crunchyroll@gmail.com).

Support link

The extension includes a link to the developer's Ko-fi page. Clicking it simply opens ko-fi.com in a new tab. Any payment happens entirely on Ko-fi under Ko-fi's privacy policy; the extension never sees or handles payment details.

What the extension never does

  • Collect, sell, rent or share any personal data
  • Use analytics, telemetry, crash reporting, advertising or tracking of any kind
  • Run on any website other than www.crunchyroll.com
  • Download or run code from the internet. All of its code ships inside the extension.
  • Use any data to determine creditworthiness or for lending purposes

Chrome Web Store limited use

The use of information received from Crunchyroll pages adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the extension's single purpose: improving how you watch videos on Crunchyroll.

Children

The extension is a general-audience tool, collects no personal information, and is not directed at children.

Changes to this policy

If what the extension stores or sends ever changes, this page will be updated before that version is released, and the effective date above will change.

Contact

Questions about privacy, or a problem with the extension: email allinone.crunchyroll@gmail.com.
